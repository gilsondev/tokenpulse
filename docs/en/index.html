How it works

The Mac does the heavy lifting and the board only draws. A Python daemon reads the Claude Code logs, fetches the % from the same API Claude Code itself uses and sends one JSON frame per second over USB.

When you tap the screen to switch org or bring a session forward, the board asks for an action from a closed list (focus, switch, login). The daemon never runs text coming from the serial port.

Install

Got a board that is already flashed? One command on the Mac is enough: see how to start. The steps below are for flashing a board from scratch.

You need a Mac with uv and Claude Code logged in. herdr and claude-swap are optional and unlock sessions by workspace and org switching.

Commands and warnings follow the chosen model.

The JC3248W535 only carries data over USB-C on one side of the plug. If the board powers on but the Mac doesn't see it, flip the plug.
The ESP32-2432S028R has resistive touch: use the stylus that comes with it. The first time it asks for four taps, one in each corner, to calibrate. Use a USB cable that carries data.
The 1.47" Waveshare has no touch: the BOOT button changes screens and holding it goes back to the main one. It auto-rotates with the accelerometer.
Connect the AMOLED 2.16" over USB-C the first time: the Mac learns its name and, when it leaves the cable, keeps sending data over Bluetooth. Holding the PWR button for 2 s powers the board off.
The SmallTV-Ultra has no data USB: everything goes over WiFi, and setup.sh doesn't work for it. The GeekMagic factory firmware is replaced and only comes back with its own .bin.

Easiest: flash from the browser

In Chrome or Edge on a computer, with the board plugged into USB, the button flashes the latest release's firmware. Then install the daemon on the Mac with one command: see how to start.

This browser can't flash over USB. Use Chrome or Edge on a computer, or the steps below. Flashing from the browser only works over HTTPS.

Flashing erases the board's settings. If tokenpulse already runs on this Mac, it holds the port: stop it with launchctl bootout gui/$UID/com.gilsondev.tokenpulse and start it again later with the same install command.

Or from the Terminal

  1. Download the project

    git clone https://github.com/gilsondev/tokenpulse
cd tokenpulse

  2. Run the installer, with the board plugged in

    It finds the board, flashes the firmware from the latest release over USB and starts the daemon at macOS login. Within a few seconds the board leaves "sem dados do Mac" (no data from the Mac) and shows your usage. The log is at ~/Library/Logs/tokenpulse.log.

    ./setup.sh guition-jc3248w535

    The first time, the ESP32-2432S028R opens the calibration: tap the center of each target with the stylus. To redo it later: Settings → About → calibrar o toque.

    The daemon runs straight from this folder: don't delete or move tokenpulse. To move it, run host/install.sh again in the new folder.

    Prefer to build it? firmware/flash.sh guition-jc3248w535 --usb and then host/install.sh.

  3. Start the daemon and send the firmware over WiFi

    Download tokenpulse-smalltv-ultra-ota.bin from the latest release and start the daemon at macOS login:

    host/install.sh

    In the factory panel, open http://<smalltv-ip>/update and upload the .bin (~460 KB, it fits in the factory OTA space). With no saved network, the board opens the tokenpulse-XXXXXX WiFi: join it from your phone, open http://192.168.4.1 and enter your network. In ~20 s the daemon finds the board and the screen leaves "sem dados do Mac".

    Prefer to build it? cd firmware && pio run -e smalltv-ultra produces firmware/.pio/build/smalltv-ultra/firmware.bin.

Update over the air, through the USB itselfover WiFi

After the first flash, the SmallTV-Ultra updates over the network. The daemon finds the board over mDNS and sends the firmware through its /update, with the same commands as the other boards. The configuration page settings stay.

After the first flash, you never need the bootloader or buttons again. The daemon that is already running sends the new firmware through the same USB cable, while the board shows the progress on screen. No Wi-Fi and no opening the case.

  1. Update to the latest release

    One command for every plugged board: it checks each one's version, downloads the *-ota.bin for the ones behind and sends it over OTA. Settings and touch calibration stay.

    ./update.sh

  2. Or build from source

    Builds with PlatformIO and sends it right after:

    firmware/flash.sh guition-jc3248w535

  3. Done in ~15 seconds

    The board restarts on the new version, which shows up in Settings → Abouton the configuration page.

1 · requestflash.sh tells the daemon which .bin to send.
2 · headerThe daemon sends the size and md5; the board opens the free partition.
3 · blocksThe firmware goes in 1 KB blocks, each acknowledged by the board.
4 · checkThe board verifies the md5 of what it wrote before switching.
5 · switchOnly then does it mark the new partition and restart.
If the upload fails halfway, the board stays on the current version: the ESP8266 only switches firmware after writing and checking the whole image. If the new firmware crashes three times in a row at boot, the board starts with only WiFi and /update, so you can send another one.
If something fails halfway (cable, mismatched md5, no answer), the board stays on the current version and shows the error. flash.sh retries once by itself when the failure is a missing answer.

Privacy

The Claude Code token is read from the Keychain on each fetch, is never stored or logged, and only goes to the Anthropic API. Emails are stripped from everything that goes to the board and to the log. Demo mode (tokend.py --demo) reads nothing of yours, and screenshots with real data require an explicit REAL=1.
