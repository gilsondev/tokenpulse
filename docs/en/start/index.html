Got a tokenpulse board?

It comes already flashed. What's left is to start, on your Mac, the program that reads your Claude Code and Codex usage and sends it to the board. It's one command, no password.

On your phone? The steps below happen on the Mac. Open gilsondev.github.io/tokenpulse/en/start there.

  1. Run this command in the Mac's Terminal

    curl -fsSL https://gilsondev.github.io/tokenpulse/install.sh | bash

    It installs uv if missing, downloads the latest release to ~/.local/share/tokenpulse and starts the daemon at macOS login. It doesn't flash firmware or touch the board. Read the script first, if you like.

  2. Connect the board

    Guition, ESP32-2432S028R or Waveshare: plug it into the Mac with a USB cable that carries data. On the Guition, if the board powers on but the screen stays at "cabo USB" (USB cable), flip the USB-C plug: only one side carries data.
    GeekMagic SmallTV-Ultra: plug it into any USB power source. The first time, the screen shows a QR code: scan it with your phone's camera to join the tokenpulse-XXXXXX WiFi. The configuration page opens by itself (otherwise, open http://192.168.4.1): pick your network from the list, the same as the Mac's, and type the password. The page tells you when it connects. Don't use the Mac's WiFi for this, or it loses internet while connected.

  3. Done

    Within a few seconds the board leaves "sem dados do Mac" (no data from the Mac) and shows the 5-hour window, the week and your sessions. The on-device UI is in Brazilian Portuguese.

Before you start

  • A Mac with macOS.
  • Claude Code, Codex or both. With Claude Code, log in once (run claude): without it the board shows Claude's tokens, but not the usage %.
  • With both on the Mac, the board asks the first time what to show: Claude only, Codex only, or both.

If it doesn't work

  • The board's waiting screen says which step is missing: cable or WiFi, daemon, data.
  • The log is at ~/Library/Logs/tokenpulse.log. The last lines usually say what happened: tail -20 ~/Library/Logs/tokenpulse.log.
  • SmallTV not showing up: check that it and the Mac are on the same network. Guest networks and separate VLANs block mDNS.
  • To update later, run the same command again.

To remove

curl -fsSL https://gilsondev.github.io/tokenpulse/install.sh | bash -s -- --uninstall
