Getting started

Got a tokenpulse board?

It comes already flashed. What's left is to start, on your computer, the program that reads your Claude Code and Codex usage and sends it to the board. Five steps and one command, no password.

  • The boardand a USB cable that carries data. Caixeta only needs a USB power source and WiFi.
  • A computer with macOS or Linuxthe same one where you use Claude Code or Codex.
  • Claude Code, Codex or bothwith Claude Code, log in once (run claude).
Continue on the computer. The steps happen there: open gilsondev.github.io/tokenpulse/en/start on the computer, or send it the link.

Step 1 of 5

Which board do you have?

The next steps change a little depending on the board. Each one is named after a Brazilian tree.

Tap your board to see its steps.

2
Step 2 of 5

Plug the board into the computer

Power Caixeta and put it on WiFi

Use a USB cable that carries data (a charge-only cable won't do). The board powers on and shows "Falta o tokenpulse" (tokenpulse is missing) with a QR code to this page: that means it's ready and waiting for the program in step 3.

The first time, the screen asks for four taps with the stylus, one per corner, to calibrate the touch.

The first connection is over the cable. After that it also works wirelessly over Bluetooth: on macOS, the system asks for permission once.

  1. Plug it into any USB power source. Its USB port only powers it.
  2. The screen shows a QR code. Scan it with your phone to join the tokenpulse-caixeta WiFi.
  3. The page that opens (or http://192.168.4.1) lists the networks. Pick the same network as the computer and type the password.
  4. The page says whether it connected. Then the screen shows the QR for this page, waiting for step 3.

Don't use the computer's WiFi to join tokenpulse-caixeta: without a network cable, it has no internet while it's on it.

If something goes wrong

The screen doesn't show tokenpulse (blank board)

The board came unflashed. Flash it from the browser on the site, with Chrome or Edge and the board plugged in. Then come back.

It powers on, but the screen stays at "cabo USB"

Flip the USB-C plug: on Sumaúma, only one side of the plug carries data.

The computer doesn't see the board

Try another cable: many cables only charge. Avoid unpowered hubs. On Linux, also see the serial port permission note in step 3.

My network doesn't show up or won't connect

Caixeta only uses 2.4 GHz networks. The page says what went wrong: password, network out of range or 5 GHz.

It still has the GeekMagic firmware

The first flash goes through its factory updater, over WiFi. See how on the site.

3
Step 3 of 5

Run this command on the computer

Open the Terminal (the command is the same on macOS and Linux), paste it and press Enter:

curl -fsSL https://gilsondev.github.io/tokenpulse/install.sh | bash

It installs the program that reads your usage and sends it to the board, and keeps it running on its own, also after a restart. No password. Read the script first, if you like.

On Linux, it installs a systemd user service. For a board on USB, your user may need to join the dialout group: if so, the installer prints the command. After running it, log out and back in.

If something goes wrong

It said "nenhuma placa ainda" (no board yet)

Check the cable (step 2). The program keeps looking: plug in the board and wait a few seconds, without running anything again.

Caixeta and the computer must be on the same network. Guest networks and separate VLANs block mDNS, which is how the computer finds the board.

It said "Claude Code sem login" (not logged in)

Run claude and log in to your account. Without the login, the board shows Claude's tokens, but not the usage %. No need to run the installer again.

Where the log is

On macOS, at ~/Library/Logs/tokenpulse.log. The last lines usually say what happened: tail -20 ~/Library/Logs/tokenpulse.log.

To remove
curl -fsSL https://gilsondev.github.io/tokenpulse/install.sh | bash -s -- --uninstall

The board goes back to "sem dados do Mac" (no data).

4
Step 4 of 5

Answer the board's questions

The first time, the board asks at most three questions, one per screen. Each one only shows up if it makes sense on your computer:

  1. Providers. If the computer uses Codex, it asks what to show: automatic, Claude only, Codex only or both.
  2. Multica. If the computer has Multica, it asks whether to show its page. By default, it stays hidden.
  3. Claude login. If Claude Code isn't logged in yet, it reminds you to run claude. You can skip it and see tokens only.

Answer by tapping the screen. Everything can change later in Ajustes (settings), via the gear.

Açaí has no touch: the screen says where to answer, and the BOOT button picks automatic.

Caixeta has no touch: the screen shows the question and you answer on the board's page, at tokenpulse-caixeta.local, from the computer or a phone on the same network.

If the board's firmware is older than the program, it updates itself first: the screen shows "Atualizando o firmware". Don't unplug the board in the meantime.

If something goes wrong

The board asked nothing

That's normal: without Codex, without Multica and with Claude Code logged in, there's nothing to ask.

I picked the wrong option

Change it in Ajustes → Provedores or Ajustes → Multica.

Change it on the board's page, under Provedores or Multica.

5
Step 5 of 5

Done

The board shows your usage live: the 5-hour window in the ring, the week, today's tokens and what each session is doing.

Swipe sideways to change screens. The gear opens the settings.

The BOOT button changes screens, and holding it goes back to the main one. It rotates on its own.

The screens cycle on their own. Brightness, time per screen and alerts live on the board's page.

Updates. When a new version comes out, the board says "Versão nova" (new version). One tap on "Atualizar agora" (update now) updates the program on the computer and then the boards' firmware, in about 1 minute. On Caixeta, the button is on the board's page.

If something goes wrong

The board went back to "sem dados do Mac" (no data)

The waiting screen says which stage is missing: cableWiFi, program or data. If the program stopped, run the step 3 command again.

It shows tokens, but not the %

Claude Code isn't logged in: run claude and log in to your account.

I want to update by hand

Run the same command from step 3. It downloads the latest version.
